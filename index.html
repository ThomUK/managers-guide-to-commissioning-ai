Just Enough AI: A Manager's Guide to Commissioning AI Capability

Eleven short modules, each built around one picture, on what large language models and AI agents are and what it takes to buy or run them. Each takes about five minutes and can be read on its own.

Every module also has a closed panel called “The detail your technical team handles”. It is there to show that the depth exists; you do not need to open it.

Part A: Using it

  • Module 1 What an LLM is You need this if you want a one-sentence answer to “what is this thing actually doing?” about 5 min
  • Module 2 Local AI vs. cloud AI You need this if you are asked to approve, buy or govern an AI tool. about 5 min
  • Module 3 A chat window vs. an agentic system You need this if someone asks you to approve an AI “agent”, or an AI tool that can take actions. about 5 min
  • Module 4 AI-assisted code development You need this if you manage people who write code or analysis, or you are asked what “AI coding tools” change. about 5 min
  • Module 5 Three ways to improve results You need this if a tool “isn’t good enough” and you are asked to fund a fix. about 5 min

Part B: Running it

Part B explains what your technical team is weighing up. Read it if you make or approve decisions about hosting AI yourselves. Otherwise Part A is enough.

  • Module 6 What a model physically is You need this if someone tells you a model “won’t fit” or “needs a bigger GPU”. about 5 min
  • Module 7 How a response gets made You need this if you want to understand why AI sometimes pauses before answering, and why long conversations cost more. about 5 min
  • Module 8 Hardware and performance You need this if you are shown a hardware quote, or told a system will be “too slow”. about 5 min
  • Module 9 Dense vs. MoE models You need this if you see a model described like “35B-A3B” or hear “mixture of experts”. about 5 min
  • Module 10 Quantisation You need this if you are told a model has been “quantised” or see labels like “4-bit”, “Q4”, “FP8”. about 5 min
  • Module 11 Putting it together You need this if you want to turn the course into questions for a real decision. about 5 min
