What an LLM is

You need this if you want a one-sentence answer to “what is this thing actually doing?”

The key idea

An LLM predicts the next small piece of text, over and over. Everything it does is built from that.

Tokens and the context window

A large language model (LLM) does not work in whole words. It works in tokens: small pieces of text, each roughly three-quarters of a word as a rule of thumb. Given some text, the model works out how likely each possible next token is, picks one, adds it to the text and repeats. An answer of several paragraphs is that one step, repeated a few hundred times.

The model can only take into account a limited amount of text at once. This is its context window: its field of view. It holds your instructions, the conversation so far and any documents you supplied. As far as the model is concerned, text outside the window does not exist.

Training and inference

The model’s ability comes from training: a one-off process, run by the model’s maker at very great expense, in which it is shown enormous amounts of text. What it learns is stored as billions of numbers called weights. Using the finished model is called inference, and it happens every time you ask something.

Chatting with a model does not change its weights. It appears to remember what you said earlier only because the whole conversation is inside its context window each time.

Plausible is not the same as true

A model produces text that is plausible given what came before. Plausible text is usually true, but not always. The model has no separate step in which it checks facts, and it writes a wrong answer in the same fluent, confident style as a right one. This is why the same tool can produce an excellent summary one minute and state something false the next. Both come from the same process.

What this means for your decisions

  • It does not look things up unless it has been given a tool to do so (module 3) or documents to read (module 5).
  • Confident wording is not evidence of accuracy. Decide where checking is needed.
  • Cost and speed are both counted in tokens (modules 2 and 7).
The detail your technical team handles optional

The architecture

Current LLMs are built on a design called the transformer. Its central mechanism, attention, lets the model weigh every token in the context window against every other when predicting the next one.

Sampling and temperature

Choosing the next token from the list of candidates is called sampling. A setting called temperature controls how adventurous the choice is: low values nearly always take the most likely token, higher values give less likely tokens more of a chance. The slider in the picture above is a temperature control.

Why the same question can give different answers

Because each token is sampled, two runs can diverge at any point, and one different token changes everything that follows. Where consistency matters, engineers lower the temperature, though even then identical output is not always guaranteed.

Knowledge cut-off

Training stops on a particular date. The model knows nothing after that date unless the information is placed in its context window.

Hallucination

“Hallucination” is the common name for fluent output that is false. It is a consequence of prediction, not a malfunction: the model is doing exactly what it always does, and the most plausible continuation happened not to be true. It is reduced by supplying sources and by checking, not eliminated.
